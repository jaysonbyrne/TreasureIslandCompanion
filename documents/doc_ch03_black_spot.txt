     [A leaf torn from a Bible, the print still legible
      at the edges.  In the centre, a round black spot,
      blackened with soot and lampblack.  Beneath it,
      in a sprawling seaman's hand:]

                    +------------------+
                    |                  |
                    |     ( black )    |
                    |     ( spot )     |
                    |                  |
                    +------------------+

               You have till ten to-night.

     [On the reverse, in the same hand, fainter:]

               Bill -- we knows where the stuff is.
               No more dodging.  Ten o'clock.
